Om sesjonen

Agile development has proven that creating and iterating upon an MVP - Minimum Viable Product - can lead to a better product, faster. For some reason, we don't apply the same principles when developing the software itself. In my more than decade of experience, we don't create MTPs - Minimum Technical Products - even when what we're building _is_ an MVP.

In this talk I'll look back at how we used to write software in "the old days", compare that to the status quo, and show you that modern software development is not only harder, but slower than it needs to be.
