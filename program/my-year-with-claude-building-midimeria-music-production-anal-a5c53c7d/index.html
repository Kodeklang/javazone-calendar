Om sesjonen

As a developer and hobby music producer I've spent the past year building a music production analytics platform alongside my day job as a consultant. An equal goal has been to find the limits of agentic development, and since Claude Code launched last spring it has been my main tool. This talk is about what I've learned and what my development process looks like now.

You probably have the skills for this already. Setting up custom AI workflows is surprisingly close to regular management and software development: clear direction, good delegation, verification of results. I'll walk you from a single prompt through composable skills to autonomous loops that fill a backlog, implement features, review code, and ship PRs - using examples from my own codebase.

We will arrive with an autonomous software development setup that can run with minimal intervention and show that the difficult task is now to set a clear direction. Agents can handle a lot, but you only get good results by guiding them, and knowing when to reach for a keyword like "red-team" to trigger a security review in two words.

Along the way: where agents are brilliant, where they stumble, and what a 1986 computer music textbook predicts about their limits.
