Om sesjonen

I got into programming because I wanted to make cool graphics, and that’s still what excites me most about coding. These days, shader coding is the ultimate playground for creating stunning real-time visuals. In this talk, I’ll start from scratch and show how to build 3D graphics using nothing but shader code. Along the way, I’ll share tips, tricks, and a bit of shader wizardry to help you get started as well.

Passer for

People that loves to code or computer graphics. They might get a new hobby or at least having a bit of fun watching the presentation. Basic programming knowledge in a C-like language.
