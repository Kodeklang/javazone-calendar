Om sesjonen

You've built a Java application, but how do you actually package, install and run it? Packaging, distribution and execution of Java applications have mostly been only a JAR-file since the beginning of Java, but in these days we can do much better.
This session takes you on a practical journey through the full landscape of Java packaging, from the humble JAR to native binaries and OS-specific installation packages.
