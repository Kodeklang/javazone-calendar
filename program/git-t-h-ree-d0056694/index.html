Om sesjonen

Git version 3 is slated for release late this year. In this lightning talk, we will take a look at its new features, notably the new SHA-256 commit ids and the "reftable" storage format. We will also take a brief look at the git worktree feature, which is relied upon by AI agents.

Passer for

Any developer who is using git, and infrastructure/devops folks who are operating git repos
