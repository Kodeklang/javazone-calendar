Om sesjonen

Join our workshop where we dive into cutting edge computer vision models and how they can be used to create your very own rendition of the classic schoolyard game "Red light, Green light".

Participants will learn how to harness a smartphone's camera, process a live video feed, and use a pre-trained pose estimation model to detect movement.

Prerequisites:
- A laptop with the required SDKs for your phone os (xcode with ios sdk for iphone, android studio with sdk for android)
- A smartphone with cable that connects to your laptop.

To make the initial setup more smooth it is also advised to go through the setup guide for Flutter.

Link : https://docs.flutter.dev/install

Passer for

This workshop aims to inspire anyone curios about mobile development using flutter, and using machine learning models for edge computing. It's accessible to any experience level.

Forberedelser

Follow the flutter setup guide, and try to run a basic project for your phone. As the SDKs are pretty large, its very benefitial to install this before the workshop, as it can take some time to download and install. Flutter setup guide: https://docs.flutter.dev/install/quick Android setup: https://docs.flutter.dev/platform-integration/android/setup iOS setup: https://docs.flutter.dev/platform-integration/ios/setup It's also suggested to go through the steps of enabling developer mode and usb debugging on your phone: IOS: https://developer.apple.com/documentation/xcode/enabling-developer-mode-on-a-device ANDROID: https://developer.android.com/studio/debug/dev-options It's also smart to update your phone to as new version of the OS as possible, to ensure maximum compatibility with the SDKs we are using.
