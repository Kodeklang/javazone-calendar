Om sesjonen

Java is gaining features to support pattern matching and a "data-oriented" programming style. In this presentation, I explore when this programming style is beneficial, and how you should structure your programs to take advantage of it. You will learn the syntax of pattern matching, as it has evolved, and you will get a glimpse at further enhancements in upcoming versions of Java. Just as importantly, I will show you how to recognize confusing and error-prone usages of pattern matching, which the new features also enable. You will come away with a mental model when to use pattern matching and "data orientation" now, how to prepare for future enhancements, and when to stay away.

Passer for

Java programmers of all experience levels who are intrigued by the notions of pattern matching and data-oriented programming
