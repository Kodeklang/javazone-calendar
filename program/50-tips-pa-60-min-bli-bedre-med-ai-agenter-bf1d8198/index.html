Kjetil er Principal Software Engineer i Telenor, der han blant annet driver interne initiativ for å ta i bruk AI-kodingsverktøy effektivt. Han publiserer jevnlig konkrete, testede tips for utviklere som vil bli bedre med AI-agenter – basert på daglig bruk av GitHub Copilot, Claude Code og OpenCode i reelle prosjekter. Å kjempe mot entropi og kognitiv last har vært en hjertesak gjennom et par tiår som engasjert utvikler og agil agitator.

Om sesjonen

Siden januar har jeg publisert AI-kodetips internt hos Telenor – ett om gangen, testet i praksis. Dette foredraget er de 50 beste.

Tipsene er basert på erfaringer fra daglig bruk.

Vi dekker mange tema knyttet til AI-agenter, for eksempel:
- Kommunikasjon: Hvordan instruksjoner, kontekst og feedback påvirker kvaliteten
- Instruksjonsfiler: AGENTS.md, skills og metadata som styrer agentens adferd
- Verktøy og automatisering: Scripts, hooks og custom tools som skalerer samarbeidet
- Arbeidsflyt: Pre-approval av tools, bruk av subagenter, og håndtering av store endringer
- Testing og kvalitet: Unngå vanlige antipatterns og få agenter til å produsere testbar kode

Hvert tips er kort, praktisk og demonstrerbart – ting du kan ta i bruk samme dag. Noen gjelder uavhengig av agent, andre er spesifikke for GitHub Copilot CLI, Claude Code eller OpenCode.

Dette er ikke en "intro til AI-koding" – det er for dere som allerede bruker AI-agenter og vil bli bedre på det. Enten du er skeptisk eller overbevist, vil du gå ut med konkrete teknikker som gjør samarbeidet med AI mer produktivt og forutsigbart.

Alle tips er publisert på https://kjetiljd.github.io/ai-for-coding/ og er brukt internt hos Telenor.

Passer for

Utviklere og tech leads som bruker AI-agenter i sitt daglige arbeid.Hva sitter du igjen med:50 konkrete tips du kan implementere umiddelbart. Du vil få en dypere forståelse av hvordan agenter tenker og hvorfor visse tilnærminger fungerer bedre enn andre.Forutsetninger:- Kjennskap til moderne utviklingsverktøy (terminal, Git, IDE)- Helst erfaring med én eller flere AI-kodingsagenter (GitHub Copilot, Claude, Cursor, etc.)- Ingen spesifikk sertifisering eller dyp AI-kunnskap nødvendig
